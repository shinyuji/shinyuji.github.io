2. 개발 배경 및 목적

  • 교육 과정 STM32 팀 과제
  • HAL 없이 레지스터 수준으로 타이머·PWM·UART·외부 인터럽트 제어 학습

3. 개발 목표

  • 버튼과 UART 명령에 따른 DC 모터 정·역회전 및 정지
  • UART 숫자 입력에 따른 속도(듀티) 변경

4. 동작 방식

  • 버튼 짧게(3초 미만): 정지 → 정회전 → 역회전 순환
  • 버튼 길게(3초 이상): 정지
  • UART F / R / S: 정회전 / 역회전 / 정지
  • UART 0~9: 듀티 50~95%

5. 주요 구현 내용

5.1 메인 루프 3단계 구조

  • 이벤트 판정 → 목표 상태 결정 → 하드웨어 반영 3단계 반복
  • 목표 상태 결정 단계는 하드웨어 미접근, 하드웨어 반영은 목표 값 변경 시에만 수행
  • 팀원별 구조안을 비교한 뒤 해당 구조 채택, 기존 코드를 이 구조로 재구성

5.2 주변장치 제어

  • TIM4 3초 타이머로 버튼 짧게·길게 누름 구분 (EXTI 버튼 입력)
  • TIM5 10kHz PWM으로 속도 제어, 반대쪽 핀은 LOW 고정으로 방향 제어
  • USART2 문자 명령 수신
  • 정회전 ↔ 역회전 즉시 전환 시 정지 후 대기, 모터 부하 방지

6. 문제 해결

6.1 코드 흐름 파악 어려움

문제
기존 코드는 모듈은 나뉘어 있었으나 main에서 동작 흐름이 보이지 않음, 팀원 간 구조 설명도 어려움
해결
팀원 각자 구조를 그려 비교, 3단계 구조로 통일해 재구성
결과
메인 루프만으로 전체 동작 흐름 파악 가능

7. 느낀 점

  • 입력 판단과 하드웨어 출력을 분리하면 코드 흐름 파악과 수정이 쉬워진다는 점
